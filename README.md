# Workforce Management System

A React-based employee management application that helps organizations manage employees, assign tasks, and track workflow efficiently. The system provides separate access for admins and employees with an interactive dashboard.

## Features

- Role-based login access for admins and employees
- Employee management dashboard
- Create, assign, and manage tasks
- Track task status and progress
- Employee details and task statistics
- Real-time task updates
- Local Storage integration for data persistence
- Responsive user interface

## Tech Stack

- React.js
- Tailwind CSS
- Context API
- JavaScript
- HTML
- CSS
- Local Storage
